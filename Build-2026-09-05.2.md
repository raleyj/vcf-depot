# VCF Offline Depot build 2026-09-05.2

This 1.0.0 rebuild is supplied for manual replacement deployment testing. Fresh deployment qualification of this exact OVA is pending. R01 and the previously completed VCF Installer-only roadmap scope remain complete. The authoritative roadmap is VCF-Offline-Depot-Roadmap.docx, revision 3.6.

## Changes included

- Compact Appliance management layout: Identity and Timezone side by side, then Management network and DNS/time, with mobile stacking.
- Removed the blue top accents from Management network, Upload and verify a release, and Create administrator.
- Inventory refresh uses the green UPDATED badge with date and time inside, matching CONNECTED and ACTIVATED. Counts and free space remain beside it.


- The depot content container starts automatically when the management service starts, including on a fresh deployment.
- Current UI, appliance management API, download activation tracking, and VCF 9.1.1 release selection are included.
- Completed setup opens Health Status. The administrator menu separates Appliance management, Appliance updates, and Admin user management.
- Appliance management includes a timezone selector populated from the operating system's installed timezone database. Saving a timezone does not reapply networking or restart NTP. The system timezone persists across reboots; NTP maintains the clock independently. Browser-rendered timestamps may use the workstation timezone, and UTC audit timestamps remain UTC.

## Set the timezone

1. Sign in and open the administrator menu, then Appliance management.
2. In Timezone, choose the required region and city, such as America/New_York, or Etc/UTC.
3. Select Save timezone and confirm the saved timezone message.
4. Open Health Status and refresh to verify the timezone under Time synchronization.
5. Set up to two NTP servers in DNS and time if required, then use Apply configuration for those changes. Timezone selection does not change the NTP server list.

## Manual replacement deployment

Use the companion Deployment Guide for vCenter or ESXi deployment. This build retains hardware version 22, 4 vCPUs, 8 GiB memory, a 32 GiB OS disk, and a new 1 TiB thin-provisioned data disk. All three deployment passwords require 15–256 characters; recovery must differ from both other passwords. DNS and NTP deployment properties accept at most two comma-separated entries. DHCP is the default; static deployment requires the network fields.

The OVA is a fresh appliance and does not migrate the existing appliance's accounts, endpoint configuration, certificates, binaries, or download history. Preserve the existing VM and its data during replacement testing. Avoid powering on both VMs with the same IP address. Upload the vendor Download Tool, authorize/download content, create depot accounts, configure HTTPS, and configure VCF Installer using the Quick Start Guide.
